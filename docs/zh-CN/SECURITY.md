# 安全策略

ScrambNet 处于 pre-alpha：一份规范和一个概念验证，还不是一个用来
保护真实秘密的系统。你能做出的最有价值的贡献，就是一次
攻破。

## 什么算作有效发现

- **设计**中的缺陷：一种在 `k` 份被截获份额之下读取内容的方法；一种
  关联同一消息各份额的方法（SP-7）；一种针对发现或路径选择的日食、女巫，或
  击溃互不相交性的攻击；任何违反
  不变量（I-1…I-4）的情形。
- `poc/` 下**概念验证**代码中的缺陷。请注意，PoC
  有意使用非常数时间的算术和玩具式构造；那些是
  已记录在案的非目标，而非发现。偏离规范，或
  代码所揭示的规范缺陷，才是一项发现。

## 如何报告

- **不敏感的设计缺陷与 PoC 问题：** 开一个公开 issue。
  公开讨论正是本仓库的意义所在。
- **你认为应当先行私下处理的任何事项：** 发送邮件至
  `scrambnet@proton.me`。请用项目密钥加密敏感报告（见
  下文）。我们力求**在 7 天内**确认收悉；若届时你仍未收到任何回复，
  请将其视作消失在了化名传递的管道之中，并在一个公开 issue 上再次
  提醒（不要带上敏感细节），好让我们注意到。

除非你希望公开，否则请不要在报告中包含你的法律身份。
化名报告同样受欢迎，并获得同等的重视。

## 范围

范围之内：`docs/` 中的规范、`poc/` 中的 PoC。范围之外：
贡献者自身设备或账户的安全；GitHub 平台本身；针对本仓库的
拒绝服务攻击。

## 项目密钥

`scrambnet@proton.me` 的 PGP 密钥已作为 [`scrambnet-pubkey.asc`](../../scrambnet-pubkey.asc)
在本仓库中发布。请用它加密敏感报告。

```
Fingerprint: E5B5 399D 751F 830D 35CB  5F4A 3087 9F3B F93D 44F7
Algorithm:   Ed25519 (sign) + Cv25519 (encrypt)
Created:     2026-11-11   Expires: 2028-11-10
```

在信任该密钥之前，请对照本文件核验指纹（并且，最好对照另一个镜像上
本文档的另一份副本一并核验）——同时在正文中*以及*作为一个已提交的文件
发布它，意义正在于两者必须一致。

使用方法：

```
gpg --import scrambnet-pubkey.asc
gpg --fingerprint scrambnet@proton.me     # 必须与上面那一行一致
gpg --encrypt --armor -r scrambnet@proton.me your-report.txt
```

**轮换（为什么密钥会过期，不变量 I-3）。** 该密钥在两年后过期；这是有意为之，
它并非一个不朽的单例。在它失效之前，下一把密钥将在此处发布，并在这把密钥
仍然有效时**由它签名**，从而使交接可被验证，而非一种盲目的信任。若这把密钥
在过期前丢失或遭到攻陷，一份吊销证书（在创建时离线生成并保管）将在此处发布，
并推送至 `keys.openpgp.org`，同时以同样的方式公布一把新密钥。没有任何单一的
披露密钥会是一个永久的信任锚点。

## 披露

对于任何可能危及未来部署用户的问题，采取协调披露；对于处在当前 pre-alpha
阶段的一切，采取立即的公开讨论——在这个阶段既没有用户会被危及，目标也是在
任何人依赖该设计之前将其攻破。
