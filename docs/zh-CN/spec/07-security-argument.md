# ScrambNet 规范 —— 第 7 部分：I-2 的安全性论证

> **非规范性翻译。** 规范版本以英文为准（[en](../../en/spec/07-security-argument.md)）。

**状态：草稿（DRAFT）。** 本部分证明——或界定——其余一切所依赖的那一条断言：无条件内容下界（I-2）。凡陈述需求（`SA-n`）之处它是规范性的，其余之处则是阐释性的。如果此处的论证是错的，那么整个项目就是错的；而查明这一点最快的办法，就是攻击*这个文件*。

这条断言是刻意收窄的。先读 §1 里的两句话；其后的一切都是对它们的论证以及它们的代价。

## 1. 被证明的是什么，用两句话

- **无条件层（下界）。** 一个观察到一条消息 `n` 份额中任意 `k−1` 份的对手，对端到端密文**一无所知**——不是「在可行范围内一无所知」，而是彻底一无所知，面对无界的计算能力与任何未来的量子计算机皆然——因为这 `k−1` 份额在*统计上独立于该秘密*（Shamir，§3 中证明）。
- **计算层（护带）。** 一个取得 `k` 份或更多份额的对手可重建密文，随后面对的是端到端 AEAD；自此，内容机密性恰好就是 ChaCha20-Poly1305 在一把对手并不持有的密钥（SP-1a）下的机密性，而这**确实是**一项计算假设。

这两层是**互斥且穷尽的**：每个对手要么持有 `< k` 份额（第 1 层），要么持有 `≥ k` 份额（第 2 层），而每一层的保证都在不援引另一层的情况下陈述。本部分其余内容严格证明第 1 层，精确陈述为何第 2 层不可能是无条件的，并钉死两层之间唯一可能互相泄漏之处（§4：AEAD 密钥在 `k` 以下必须不可见）。

```
  对手持有多少份额所划出的两层

   shares held:   0 ........... k-1   │ k ........... n
                  └──── 第 1 层 ────┘ │ └──── 第 2 层 ────┘
                                      │
   第 1 层（低于 k）                  │   第 2 层（k 或更多）
   ─────────────────                  │   ───────────────────
   这 k-1 份额在统计上                │   对手重建 C，随后遇到
   独立于秘密（SA-1, SA-2）           │   密钥 K 下的端到端 AEAD
          │                           │          │
          ▼                           │          ▼
   无可学之物，面对                   │   机密性 = ChaCha20-
   无界计算与任何量子计算机           │   Poly1305 在对手不持有
          │                           │   的 K 下（SP-1a）
          ▼                           │          │
   无条件（下界）                     │          ▼
                                      │   计算型（护带）

   接缝（SA-4）：K 从不出现在任何低于 k 的对手所见之物中。
   这正是阻止第 1 层悄然衰变为第 2 层之所在——下界隐藏
   C，而对手对未来某个 C 的 K 也一无所获。
```

## 2. 模型与对手

- 一条**消息**是一个字节串 `M`。发送者首先计算密文 `C = AEAD-Seal(K, N, M)`（SP-1a），其中 `K = HKDF(kpair, "e2e-content")` 而 `N` 是消息随机数（nonce）。进入分散的是 `C`——绝不是 `M`。
- 分散是 GF(2⁸) 上的 `(n, k)` Shamir，**逐字节**进行：对于字节位置 `j`，秘密字节 `c_j` 是一个独立、均匀随机的 `(k−1)` 次多项式 `f_j` 的常数项，而位置 `j` 处的第 `i` 份额为 `f_j(i)`，其求值点为互异且非零的 `x_1,…,x_n ∈ GF(2⁸)\{0}`（份额索引）。「独立、均匀」是承重的，其本身就是一项需求（下文 SA-3）。
- **`k` 以下对手**所见为：任意 `k−1` 份完整份额（这 `k−1` 个索引的每一个字节位置），外加一切公开信息——规范、求值点、`n`、`k`、其他数据包的线路字节。它**看不到** `K`、`N`，也看不到其 `k−1` 份之外的任何份额。它拥有无界的计算能力。
- 我们证明的是关于 `C`（密文）的一条性质。对手最终想要的是 `M`；§4 表明 `C` 层面的结果可传递到 `M`，因为 `K` 不在对手的视野之内。

## 3. 下界：任意 `k−1` 份额独立于秘密（第 1 层）

**SA-1（逐字节完美保密）。** 固定一个字节位置 `j`。令秘密字节为 `s = c_j`，多项式为 `f_j(x) = s + a_1 x + … + a_{k−1} x^{k−1}`，其中 `a_1,…,a_{k−1}` 在 GF(2⁸) 上独立且均匀。对任意一组 `k−1` 个互异非零点 `x_{i_1},…,x_{i_{k−1}}` 与任意目标值 `y_1,…,y_{k−1}`：

> 对所有 `t` 满足 `f_j(x_{i_t}) = y_t` 的系数元组 `(a_1,…,a_{k−1})` 的数量，**对每一个候选 `s` 恰好为一个**。

*证明。* 固定 `s`。这 `k−1` 个方程 `f_j(x_{i_t}) = y_t` 关于 `k−1` 个未知量 `a_1,…,a_{k−1}` 是线性的；其系数矩阵是在互异非零点 `x_{i_t}` 上的 Vandermonde 矩阵（列为 `x, x², …, x^{k−1}`），它在该域上可逆。于是对每个 `s` 恰有一个解。因此 `Pr[shares = (y_1,…,y_{k−1}) | secret = s]` 对每个 `s` 都相同（`= 1 / 256^{k−1}`）：份额与 `s` **独立**。∎

这正是 PoC 对 `k = 3` 以暴力枚举所运行的那件事（`poc/dispersal.py`，`floor_demo()`——全部 256 个候选字节都同样一致地回来，且各自恰以一种方式）。SA-1 是该演示对某一情形所检验内容的一般化陈述。

**SA-2（整个秘密，而非单字节——联合独立性）。** 令密文为 `C = c_1 c_2 … c_L`（全部 `L` 个字节）。发送者为这 `L` 个位置**独立地**抽取系数元组（SA-3）。那么完整的 `k−1`-份额视图——持于 `k−1` 个索引处的长度为 `L` 的字节串——与 `C` *联合*独立：

> `Pr[view = v | C = c]` 对每一个 `c ∈ (GF(2⁸))^L` 都相同。

*证明。* 视图在各位置上可分解：对手在位置 `j` 所见的字节仅取决于 `(c_j, a^{(j)}_1,…,a^{(j)}_{k−1})`，而跨位置的系数抽取是独立的（SA-3）。于是 `Pr[view = v | C = c] = ∏_{j=1}^{L} Pr[view_j = v_j | c_j]`，并且由 SA-1，不论 `c_j` 为何，每个因子都等于 `1/256^{k−1}`。因此该乘积对**每一个** `c` 都为 `1/256^{(k−1)L}`。与 `C` 的独立性随之成立。∎

SA-2 正是 PoC 旧测试**未曾**覆盖的那一步：`floor_demo()` 只是单字节，而统计测试只检验了一个边缘分布（单个位置的分布）。「跨位置取乘积」的论证正是使下界成为一个关于*消息*的陈述的关键，而它成立**仅仅因为**各位置的系数是独立的——这恰是 SA-3 所防范的失效模式。

**SA-3（系数随机性对下界至关重要）。「[规范性]」** 多项式系数 `a^{(j)}_t` 必须（MUST）取自一个密码学安全的 RNG，并在系数索引 `t` 与字节位置 `j` 两个维度上独立抽取。下界恰好与这份随机性一样强，不会更强：

- **跨位置重用**（例如一个系数元组被每个字节重用，或者一串短而重复的系数密钥流）会破坏 SA-2 的独立性：分解失败，`k−1` 份额与 `C` 变得*相关*，对手可通过跨位置的互相关获得关于 `C` 的信息。建立在重用系数之上的下界不是下界。
- **低熵 RNG**（一个弱的或可预测的生成器）会使 SA-1 的均匀抽取坍塌：如果对手能预测或枚举系数分布，那么「每个 `s` 恰有一个一致元组」的计数便不再在 `s` 上均匀，份额就会泄漏。

这是整部规范中最重要的唯一一条实现需求。它满足起来成本低廉，而弄错则是灾难性的；并且与 AEAD 的弱点不同，它无法通过之后轮换密钥来修复——一条在坏系数下拆分的消息永远被攻破。一个合规的实现必须（MUST）将系数 RNG 视为其最高保障级别的组件（另见参考密码学需求，roadmap 3.1）。

## 4. 接缝：AEAD 密钥在 `k` 以下必须不可见（两层之间不泄漏）

SA-2 证明了 `k−1` 份额独立于**密文 `C`**。对手想要的是**明文 `M`**。桥梁在于 `M = AEAD-Open(K,N,C)`，而 `k` 以下对手并不持有 `K`。这仅在 `K` 从不出现在该对手所见的任何东西之中时才成立——而这是一项需求，并非巧合：

**SA-4（跨下界的密钥分离）。「[规范性]」** 不得（MUST NOT）有任何可由 `k` 以下对手推导出的值泄露 `K = HKDF(kpair, "e2e-content")` 或 `kpair`。具体而言：

- `K` 不得（MUST NOT）被置于任何份额、标签或数据包字段之中。（在本设计中并未如此：`K` 仅在端点使用，用于封存与开启 `C`；份额承载的是 `C` 的字节，而 SP-7 标签是从一把*经标签分离的*密钥 `HKDF(kpair, "tag")` 导出的，而非从 `K` 导出——见 §5 与 SP-7a。）
- 因此 `k` 以下对手的视图既独立于 `C`（SA-2），**又**不携带关于 `K` 的任何信息。它既读不到 `C`（那里什么都没有），也拿不到 `K` 去攻击未来的某个 `C`。两层互不泄漏。

倘若 SA-4 被违反——倘若某个 `k` 以下可观察的值是 `K` 的函数——那么下界仍会隐藏*这一个* `C`，但对手可以收割 `K`，并在其之后取得 `k` 份额的那一刻读取它，或者读取同一把 `K` 下的*其他*消息。SA-4 正是使无条件层不致悄然沦为计算型的那道保障。

## 5. 为何第 2 层是计算型的，坦诚地讲

在 `k` 份或更多份额时，对手精确地重建 `C`（Lagrange 插值——这是*预期*的路径，收件人正是以此读信）。从 `C` 出发，`M` 的机密性恰好就是 ChaCha20-Poly1305 在 `K` 下的机密性。这是一项计算假设：原则上它可被对该密码的密码分析攻破。它**不会**被一台未来的量子计算机经由 Shor 攻破，因为 `K` 来自一份预共享的*对称*秘密，不存在任何可供反演的 Diffie-Hellman 记录（SP-1a）；Grover 至多使有效密钥长度减半，故有 ≥256 位的建议。所以对第 2 层坦诚的陈述是：*与一把对手并不持有的密钥下的对称 AEAD 一样强，不会更强*——这是一项真实、常规、量子感知的计算型保证，而非无条件的保证。本项目从不作其他宣称，并且每一份公开文档如今都陈述了这一规制（roadmap 0.1）。

## 6. 本部分**未**证明的是什么

- **关联性 / 元数据。** I-2 关乎内容，而非谁与谁交谈。此处没有任何东西隐藏*某条*流曾在一条被捕获的份额路径上发生过；那是威胁模型所承认的残余风险，被分散所收窄，而非被消除。
- **可用性。** 一个处于份额路径上的敌意方可以损坏或丢弃某份额；AEAD 会 fail-closed（SP-7a），所以这是拒绝服务，而非泄露。SA-1…SA-4 对消息是否*到达*只字未言，只关乎一个 `k` 以下对手在消息未到达时*学到*什么。
- **份额之间的时序关联（SP-9 / OP-4）。** SA-2 关乎份额的*取值*，而非它们的发出时刻。在毫秒之内进入网络的 `n` 份额是一枚指纹，哪怕它们的字节独立于 `C`。那是一个开放问题，而非这份证明所处理之事。
- **AEAD 本身。** 第 2 层继承 ChaCha20-Poly1305 为真的一切。若该密码倒下，第 2 层随之倒下；下界（第 1 层）不会。

## 7. 本部分引入的需求

- **SA-1** —— 任意 `k−1` 份额的逐字节完美保密（已证明）。
- **SA-2** —— 对整个秘密的联合独立性（在 SA-3 之下已证明）。
- **SA-3** —— *系数随机性对下界至关重要*：CSPRNG，在每个位置与每个系数上独立。**「[规范性，最高保障]」**
- **SA-4** —— 跨下界的密钥分离：没有任何 `k` 以下可观察的值泄露 `K` 或 `kpair`。**「[规范性]」**

SA-1 与 SA-2 是定理；SA-3 与 SA-4 是使这些定理描述真实系统的两个条件。攻破这四者中的任意一个——找到一个证明所遗漏的视图、一个 SA-3 放过的相关、一个承载 `K` 的字段——你就攻破了 I-2。这就是邀请。
