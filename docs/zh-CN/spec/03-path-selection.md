# ScrambNet 规范 —— 第 3 部分：链路构建与路径选择

**状态：草稿（DRAFT），也是本规范中最不稳定的部分。** 这是*运维*安全的承重墙
（I-2 所保障的内容下界没有它也能成立，但抗关联保护与整套 k-路径的故事都栖身于此）。
临时取值以 `(s)` 标记。disjoint（互不相交）性的验证问题即 OP-1，且公开地悬而未决；
本部分陈述目标，并给出一个可供攻击的首个机制。

## 1. 范围，以及为什么这很难

分散（第 1 部分）使内容在被捕获的 `k` 份额以下无条件安全。只有当 `n` 条份额链路
真正互不相交时，那条保证才在*运维*意义上成立——否则对手的单个观测点便能看见 `k`
份额，而那条下界虽在数学上完好无损，却永远无法企及。本部分决定一个客户端——它仅持有
自己那份可验证的 gossip 抽样（第 2 部分），并无任何可信地图——如何选出 `n` 条让对手
无法廉价地横跨其上的链路。此处的一切都必须能抵挡这样的中继：它们对一切都撒谎，唯独
对其签名所绑定之物不能（GR-2）。

## 2. 互不相交性目标

- **PS-1.** 一条消息的 `n` 条链路必须（MUST）*按节点互不相交*：没有任何中继出现在
  其中两条之上。这是下界，只要抽样足够大便始终可强制施行。
- **PS-2.** 客户端应当（SHOULD）另行追求如下目标，按价值递减、难度递增的顺序：
  **按 AS 互不相交**（没有任何两条链路在守卫或出口处共享同一自治系统），其次
  **按司法辖区互不相交**（没有任何两条共享同一法律辖区）。它无法满足的每一层级都
  必须（MUST）向用户报告，而非悄然跳过（PS-9）。
- **PS-3.** 在同一条链路内，守卫、中间节点与出口必须（MUST）按节点各不相同，并应当
  （SHOULD）按 AS 各不相同。一条守卫与出口共享同一 AS 的链路，是送给端到端关联的
  大礼，只要存在任何替代方案便禁止（MUST NOT）使用。

## 3. 无需自我申报的推断

- **PS-4.** GR-3 禁止中继申报其位置，因此客户端从每个中继的 `addrs` 出发，使用
  *自己的*数据集（例如一份定期刷新的 IP-到-AS 映射）来推断该中继的 AS 与司法辖区，
  绝不采信中继自身所言。该数据集的分发本身必须（MUST）遵守 I-3：不存在任何单一的
  权威来源（候选设计即 OP-1）。
- **PS-5.** 推断是不确定的，客户端必须（MUST）如此对待它：当某中继的 AS 或司法辖区
  未知时，它便计为与其他每一个未知项*可能共享*——取保守假设，绝不取乐观假设。

## 4. 守卫

- **PS-6.** 每个客户端维护一小组**守卫中继**（临时方案：每个链路位置一个主守卫，
  按月而非按分钟的节奏轮换），沿用 Tor 的守卫论证：快速轮换入口点会成倍放大最终抽中
  一个敌意入口的概率。各守卫之间必须（MUST）选为按 AS 互不相交，使得 `n` 条链路不会
  在入口处汇集穿过同一个 AS。
- **PS-7.** 守卫的选取按*已验证*带宽（GR-7）加权，绝不按声称的带宽；一个带有无法
  验证之声称的中继，被当作低带宽处理，而非高带宽。

## 5. 小型网络：降级，并把它说出来

- **PS-8.** 当客户端已验证的抽样无法提供 `n` 条按 AS 互不相交的链路时，它必须
  （MUST）按固定顺序回退——按 AS 互不相交 → 按节点互不相交 → 独立抽取——并且不得
  （MUST NOT）悄然像更强的性质仍然成立那样继续下去。当估计出的可行规模未达标时，
  参数可以（MAY）下调（小型网络模式：`n = 2, k = 2`，并尽力而为地做到互不相交）。
- **PS-9.** 客户端必须（MUST）将一条消息实际达到的互不相交层级，以非专家也能正确
  读懂的措辞公开出来：今天的人群很小；这就是你买到的东西。内容下界（I-2）与关联层级
  是彼此独立的陈述，必须（MUST）分别展示。

- **PS-10（抗女巫的规模估计）。** 可行规模的估计必须（MUST）只计入独立验证过的中继
  与观测到的 AS 多样性，绝不计入原始的记录条数，以免对手用女巫节点把网络吹胀，从而
  诱使客户端采用其多样性为假的完整参数（与 OP-2 相关联）。

- **PS-11（被认定的互不相交性并非真正的互不相交性）。** 客户端所构建的保护，其优劣
  上限不过等同于它的推断数据集，客户端必须（MUST）把该数据集的错误率当作头等的安全
  参数，而非实现细节。模拟器（`poc/network_sim.py`，§1）将对手所利用的*真实底况*与
  客户端的*认定*区分开来，并扫过推断错误率：随着错误上升，按 AS 互不相交的选取会部分
  沦为幻觉，内容攻破率与关联泄漏二者都单调上升。有两条推论具有规范性：（a）对于
  **随机**推断误差（噪声，一份仅仅是不准确的地图），该误差对**关联的侵蚀远快于对
  内容的侵蚀**——一次内容攻破仍需对手同时处于 `≥ k` 条链路之上，故在元数据率先劣化
  之际下界依然成立；UI 不得（MUST NOT）把一个很低的内容攻破数字呈现得仿佛它同时也
  为关联设定了界限。这种不对称性**仅对随机误差**成立；一份*被对手择定*的地图不是
  噪声（见 PS-12）；（b）更稀薄的 **gossip 抽样**（PS-10，I-3）会
  更早地迫使回退：一个认识的中继太少的客户端根本无法构建按 AS 互不相交的链路，只能
  跌落至 `none`，此时攻破率陡然跳升（§2）。因此可行规模的估计（PS-10）必须（MUST）
  以*可达*的抽样为准，而非以整个网络为准。零错误、完整视图下的数字是最佳情形；一个
  合规的客户端必须（MUST）呈现其从真实、带噪、局部的视图中所达到的层级（PS-9）。
- **PS-12（一份敌意地图不得将选取操纵到对手之上）。** `[claim-critical]` 一份
  *被对手择定*的地图不是随机误差，PS-11(a) 的不对称性**不**能防御它。一份对手所控制的
  地图对按 AS 互不相交的选取握有两个杠杆：给对手自己的同址中继以*互不相同的*伪造 AS
  （从而它们永不彼此排除），并给*诚实*中继以*相互碰撞的*伪造 AS（从而一旦链路 1 选中
  一个诚实中继，其余每一个诚实中继看起来都与之按 AS 共享，于是被滤除）。诚实候选池
  便在首次抽取之后塌缩，客户端几乎完全从对手中继里选出链路 2…`n`——把对手*确定性地*
  落在 `≥ k` 条链路的守卫**与**出口之上，一次*内容*攻破，而客户端仍认定自己达到了
  按 AS 互不相交，并且不发出任何回退警告。已对 `poc/network_sim.py` 演示：一份操纵
  地图将内容攻破率从约 0% 推到**在约 15% 的对手占有率下达到 100%**（相比之下，一份
  诚实地图在 35% 时为个位数的低攻破率）。所以**一份坏地图能够触及内容，而不只是关联**
  （这更正了此前一处过度陈述；第 8 部分 ID-8a 已被更正以相符）。一个合规客户端必须
  （MUST）施加的防御：
  1. **不要让地图独自就能塌缩诚实池。** 客户端不得（MUST NOT）构建这样一个链路集合：
     其中超过一个有界份额的链路，就其所声称的相互互不相交性而言，依赖于客户端无法
     *独立*佐证其为相异的中继（GR-8 来源混合，PS-10「只计数独立验证过的」）。如果
     被认定为互不相交的选取会从一个被地图弄得可疑地小的池里抽取链路 2…`n`，客户端
     必须（MUST）将其当作一个回退/异常状况（PS-8、PS-9），而非一次成功。
  2. **一份蕴含不可信 AS 结构的地图本身就是一个异常。** 若在某份地图之下，客户端的
     *可达诚实抽样*塌缩为一个或少数几个 AS，而被对手塑形的其余部分却极度多样，这便是
     操纵的签名；客户端应当（SHOULD）将其作为地图异常 gossip 出去（第 8 部分 ID-10）
     并回退。
  3. **重建才是真正的防御。** 一份操纵地图无法从公开输入复现（第 8 部分 ID-5a）；
     一个重建了的、或与一个重建了的诚实对端取得一致的客户端，会拒绝它。在此之前，
     客户端必须（MUST）把一份未验证地图的互不相交性声称当作未验证，而非已达到（PS-9）。
  诚实的残余仍在：在一个已接受一份未验证操纵地图、且尚无法重建的客户端的日蚀窗口
  之内，内容下界可能坍落。这由 `k`/`n` 的余量以及上述防御来界定，而非由一个「它不会
  发生」的声称来界定。

## 6. 验证程序（PS-13…PS-19）

### 6.1 程序及其证书

- **PS-13（该程序是三项申报输入的纯函数）。**
  `[claim-critical]` 链路构建必须（MUST）可表达为一个确定性函数
  ```
      verify(sample, map, corroboration, n, k)  ->  (circuits, certificate)
  ```
  恰以三项客户端侧输入为参数，别无其他：
  - **`sample`**——客户端已验证的中继 gossip 抽样（第 2 部分，按 PS-10 计数：*仅限
    独立验证过的中继*）；
  - **`map`**——第 8 部分的推断地图，以其哈希 `H` 命名，并携带其自身实测的错误率 `e`
    （ID-12）；
  - **`corroboration`**——一个逐中继的数值 `c_j ∈ [0,1]`，陈述该中继被推断出的
    AS/司法辖区获得了多么独立的佐证（PS-15）。
  输出是 `n` 条链路**以及**一份**互不相交性证书**（PS-14）。任何一步都不得读取中继
  自我申报的位置（GR-3、PS-4）、一份可信目录（I-3）或底况真相（并不存在可读的真相
  ——这正是整个问题所在）。一个合规实现若无法把它的选取表达为这个纯函数，就无法发出
  一份可核查的证书，因而不合规：一个持有本规范与同样三项输入的实现者必须（MUST）能够
  重建出同样的「链路与证书」决策（I-1）。

- **PS-14（证书包含什么——以及它如何可被机器核查）。**
  `[claim-critical]` 该证书是一份规范-CBOR 记录（第 0 部分编码），**恰好**携带第二方
  为**重算并确认**它所需的字段，而不含任何要求被信任的字段：
  1. **`map_hash`**——证书所据以计算的那个 `H`（ID-2）。离了它证书便毫无意义：
     *「按 AS 互不相交」*从不是一个独立成立的声称，只有*「在地图 `H` 之下按 AS
     互不相交」*才是。
  2. **`map_error`**——地图随附的二元组 `(mismap_rate, unknown_rate)`（ID-12），
     逐字抄录，使核查者无需重新测量它。二者之和即下文所用的逐次查询错误 `e`。
  3. **`circuits`**——对 `n` 条链路中的每一条，给出守卫/中间节点/出口处的中继 ID
     （GR-2 密钥指纹），并对各**枢轴**（守卫与出口——AS 级对手所关联的那两个位置，
     PS-3）给出地图所赋予的**认定** `(AS, jurisdiction)`，或 `unknown`。
  4. **`corroboration`**——所用的逐枢轴 `c_j`（PS-15），使核查者以同样的折减来重算。
  5. **`class`**——所达到的互不相交层级，取 `as` / `node` / `none` 之一（PS-2 顺序），
     即该集合在地图之下实际满足的*最强*性质，而非所请求的那个。
  6. **`confidence`**——一个 `[0,1]` 中的数（PS-16），即在地图的误差区间与佐证之下，
     `class` 声称成立之概率的保守下界。
  7. **`steering_flag`**——PS-12 检测器对客户端**完整可达抽样**所作的裁定（PS-17），
     以及其背后的池存活比。
  一个**持有同一地图 `H`** 的核查者必须（MUST）能够：（a）在 `H` 中重新查询每个枢轴
  的 `(AS, jurisdiction)`，并确认它与字段 3 相符；（b）按 PS-2 互不相交性检验，从那些
  查询结果重算 `class`；（c）**按所申报的方式**用 PS-16 公式从字段 2、4、5 与 7 重算
  `confidence`；（d）确认该记录内部自洽。若任何一次重算不一致，该证书**无效**，必须
  （MUST）予以拒绝（它是对着另一份地图算出的，或系伪造）。该证书不绑定任何签名：正如
  地图本身（ID-11）一样，**裁决者是复现，而非签名。**

  **核查者能与不能重新推导什么——如实陈述（一次敌意审查的发现）。** 有两个字段是
  *发起方客户端所测量的输入*，而非远程核查者能单凭 `H` 重算的量：
  `steering_flag`/`pool_survival` 是**那个客户端的完整可达 gossip 抽样**的函数
  （PS-17），而它并非一个证书字段；每个 `c_j` 则是那个客户端的**佐证测量**（PS-15），
  同样无法单凭 `H` 重新推导。因此该证书是**相对于其所申报的输入**可核查的——核查者
  确认该置信度是否按 PS-16 公式从所陈述的 `map_error`、`corroboration` 与
  `steering_flag` 推出——但它**并非**一个无条件的证明：一个就自己的 `c_j` 向上**撒谎**、
  或略去一个其抽样本会触发的操纵标志的客户端，产生的证书重算起来*自洽*，却仍然错误。
  对此的防御不在证书之内，而在网络之中：一个在同一 `H` 与重叠抽样之上的独立客户端会
  推导出一份**不同的**证书，而这一分歧会像地图分歧一样被作为异常 gossip 出去（PS-19、
  ID-10）。证书消除的是*悄无声息的*「按 AS 互不相交：是」；它并不能使一个撒谎客户端的
  置信度自证成立。这是一个被申报的限度（§6.6），而非一个被藏起来的限度。

### 6.2 佐证：逐中继的置信度输入

- **PS-15（逐中继佐证是独立的相互印证，像 PS-10 那样计数）。**
  一个中继的输入 `c_j` **不是**一个信任评分，并且不得（MUST NOT）取自该中继或任何
  单一方。它是该中继被推断出的 AS 获得**独立佐证**的程度——与 PS-10 施于规模估计、
  GR-8 施于 gossip 的那套「只计数独立验证过的」纪律相同：
  - `c_j = 0`——该中继的 AS **仅**来自地图 `H` **而别无其他**；客户端没有第二个观测
    视角。这是默认值，也是保守的下界。
  - 随着**独立、来源混合的**观测视角（GR-8）对该中继的同一推断 AS 取得一致，`c_j`
    向 `1` 上升：来自一组互不相交采集器的第二份可复现构建的地图（ID-3a）、对该中继
    所宣告前缀的带外观测、一个对端 gossip 过来且相符的证书枢轴。临时方案（s）：
    `c_j = 1 − 2^(−v)`，其中 `v` 为独立佐证视角数（一个视角 ⇒ 0.5，两个 ⇒ 0.75，
    …），被封顶于 `1` 以下，因为任何有限数目的覆盖层视角都看不见那个机架（§6.6）。
  一个被地图标为 `unknown` 的中继，其 `c_j = 0`，**并且**贡献一个本已保守的 `unknown`
  认定 AS（PS-5）：它与一切相碰撞，故它鲜能存活到一个枢轴位置；而当它真的存活下来时，
  置信度公式早已把它当作完全不确定来处理（PS-16）。在 GR-8/PS-10 的来源混合尚未施加
  之前，不得（MUST NOT）从*多少个*对端报告某个取值来推断佐证——一个女巫无法凭纯粹的
  数量把一个中继的 AS 投票成高佐证（与 OP-2 相关联，正如 ID-9）。

### 6.3 置信度公式

- **PS-16（置信度是一个保守的、独立误标下界）。**
  `[claim-critical]` 设一个链路集合的**枢轴**为 `n` 条链路中处于守卫或出口位置的
  相异中继（至多 `2n` 个，去重后更少）。所声称的互不相交性**仅当没有任何枢轴以如下
  方式被误标时**才成立：这种误标把一对被认定为相异的枢轴变成一对真正碰撞的枢轴。
  地图随附逐次查询错误 `e = mismap_rate + unknown_rate`（ID-12）；佐证把一个枢轴的
  **有效**误标概率折减为
  ```
      p_j = e · (1 − c_j).
  ```
  将逐枢轴误标视作**相互独立**，则证书对 `class = as` 的 `confidence` 为如下乘积
  ```
      confidence  =  Π_j ( 1 − e · (1 − c_j) )       over pivots j,
  ```
  并被 PS-17 操纵闸门压至下界 `0`。对 `class = node`，互不相交性根本不依赖地图（节点
  身份由 GR-2 绑定，而非推断），故 `confidence = 1 − (PS-17 闸门)`。对 `class = none`，
  按定义 `confidence = 0`：未声称任何互不相交性，故亦不为任何互不相交性背书。

  **独立性假设，被点明并论证其为保守。** 真实的枢轴误标**并非**相互独立：地图中一条
  错误的 BGP 前缀会一次性误标其下的每一个中继（正相关）。我们仍然假设独立性，而这在
  *下界*所看重的方向上是**保守的**：当多个枢轴共享一个误标成因时，乘积 `Π(1 − p_j)`
  *低估*了那个*相关*的情形——当误标相关时，*至少一个*枢轴出错的概率**低于**独立乘积
  所暗示的值，故真实的「所有枢轴皆正确」概率**高于**我们的下界。因此该乘积是置信度的
  一个下限，即它永不夸大安全性。独立性会让我们*过度*自信之处，是一个共享的*诚实*成因
  （一个巨大而正确的 AS），而它并不威胁互不相交性；敌意的共享成因——一份把池塌缩掉的
  地图——根本不由该乘积处理，而由 PS-17 闸门处理，后者不论乘积如何都把置信度压至 0。
  于是两种失效形态被干净地分开：**随机/相关的地图误差 → 乘积（保守）；敌意的地图结构
  → 闸门（硬下界）。**

  有据可依（并非空谈）。对着 `poc/network_sim.py`，在无佐证（`c_j = 0`，故 `p_j = e`）
  之下，`1 − confidence` 在每一个错误水平上都为枢轴的**实测**真实-AS 碰撞率提供上界
  ——例如在 `e = 0.2` 时，`1 − confidence ≈ 0.83`，而实测的真实-互不相交性失败率
  为 `≈ 0.18`：偏悲观，这正是一个安全下界的正确方向，绝非偏乐观。佐证会单调地将其
  恢复（在 `e = 0.2` 时，随着均匀的 `c_j` 走 `0 → 0.5 → 0.9 → 1.0`，平均置信度上升
  `0.17 → 0.43 → 0.84 → 0.99`）。一个合规客户端应当（SHOULD）呈现这种如实的悲观，
  而不是用一个假设超出三项申报输入所能支撑之内容的模型去收紧这个下界——一个站得住脚
  的下界胜过虚假的精确（PS-11）。

### 6.4 按构造即对 PS-12 稳健

- **PS-17（操纵闸门把置信度压至下界——在正确的信号上、在完整可达抽样之上）。**
  `[claim-critical]` 在报出 PS-16 的乘积之前，程序必须（MUST）对客户端的**整个可达
  gossip 抽样**——而非那 `2n` 个被选中的枢轴——施加 PS-12 防御-2 检测器
  （`detect_steering`）：那个结构栖身于*群体*之中，等到枢轴被抽出时已从枢轴里消失
  （单查枢轴只能在约一半的消息上抓住一份操纵地图）。**信号必须是对手无法回避的那一个。**
  这个检测器的第一个版本以「一个巨大的认定 AS 容纳着被塌缩的诚实池，四周环绕着单例」
  为触发键，而一次敌意审查**绕过了它**：它改为把诚实池塌缩进*少数几个*伪造 AS 而非
  一个巨大的 AS——没有巨型 AS，检测器沉默，内容在约 30% 的消息上被攻破。正确的、承重
  的信号是**反常的单例比例**：为了让它的同址中继看起来按 AS 互不相交，对手必须（MUST）
  给每个中继一个各不相同的伪造 AS，即把它们造成单例，而一个真实网络只有极少的单例 AS。
  因此检测器必须（MUST）在如下情形触发：单例中继超过抽样的一个小比例，**并且**非单例
  中继挤在太少的拥挤 AS 里以致无法构建 `n` 条互不相交的链路（第二个条款使推断*噪声*
  ——它同样会制造单例——不会把它绊响）。对着 `poc/network_sim.py` 实测
  （`make_steering_map(honest_groups=g)` / 修好的 `detect_steering`）：它在**有效**的
  操纵区间（`g = 1…5`，10–100% 的内容攻破）上以约 100% 的比率将其抓住，而对诚实地图
  即便在高达 0.4 的推断错误下也有 **0%** 的误报。因此：
  - 若检测器在可达抽样上触发，证书必须（MUST）置 `steering_flag = true`、
    `class = none`、`confidence = 0`，且客户端必须（MUST）把该结果当作 PS-12
    回退/异常状况处理（gossip 出去，ID-10；降级并把它说出来，PS-8/PS-9）——它不得
    （MUST NOT）发出一份 `as` 证书。
  - **被申报的残余：** 一份*边缘的*操纵地图，它把诚实池铺散到足够多的伪造 AS 之上
    （`g ≥ 8`）以构建出真正互不相交的链路，便逃过了检测器——但在那里它的内容攻破
    仅约 5%，与一个小型合法网络无从分辨，并由 `k`/`n` 余量与 PS-16 置信度来界定，
    而非由一个「它不会发生」的声称来界定（§6.6）。

- **PS-18（池塌缩前置条件——PS-12 防御 1，折叠为一项置信度输入）。**
  `[claim-critical]` 独立于那个结构性检测器，程序必须（MUST）计算**诚实池存活比**：
  即可达的、经独立佐证的抽样（PS-10，PS-15 且 `c_j > 0`）中，**在**第一条链路被抽出
  **之后**仍为一个*被认定为相异 AS*之候选的那个份额。当链路 `2…n` 是从一个被地图塌缩
  到某个有界份额以下的池里抽出时（临时方案（s）：存活 `< 1/n` 的经佐证诚实抽样），
  证书不得（MUST NOT）声称 `class = as`，因为那样一来，该集合所声称的相互互不相交性
  就栖身于客户端无法*独立*佐证其为相异的中继之上——这恰是 PS-12 防御 1。在那种情形下，
  程序必须（MUST）要么把 `class` 降为 `node`（整个丢弃依赖地图的声称），要么如 PS-17
  那样置入异常状况。**置信度之所以低，恰恰在 PS-12 说客户端正被操纵之时：** 闸门在那个
  结构性签名上把它归零，而存活前置条件在池可疑地稀薄时剥去 `as` 声称——如此一来，一份
  操纵地图无法凭任何一个杠杆（互不相同的伪造对手 AS，或相互碰撞的伪造诚实 AS）挣得一份
  高置信度的 `as` 证书。这是那条不可让渡的性质，而它是被验证的，不是被断言的：PS-12
  测试所显示的、把一次 100% 内容攻破转为一次 100% 回退的那同一道闸门，在 100% 的操纵
  地图上把证书置信度驱至 0。

### 6.5 一份带数值的证书

输入：`n = 4`，`k = 3`；一份健康的抽样；地图 `H = 0x9f2c…a17b`，随附
`map_error = (0.04, 0.03)` 故 `e = 0.07`；那 8 个枢轴（4 个守卫 + 4 个出口）——其中 6
个由一个额外的独立视角佐证（`c_j = 0.5`），2 个仅依赖地图（`c_j = 0.0`）；操纵检测器在
可达抽样上**未**触发。于是那六个的 `p_j = 0.035`，那两个的 `p_j = 0.07`，
`confidence = (1−0.035)^6 · (1−0.07)^2 = 0.698`。

```
disjointness-certificate (canonical CBOR; shown as a record):
  map_hash      : 0x9f2c3e...a17b
  map_error     : { mismap: 0.04, unknown: 0.03 }         # e = 0.07 (ID-12)
  class         : "as"                                     # 所满足的最强者, PS-2
  confidence    : 0.698                                    # PS-16 乘积, gate=1
  steering_flag : false                                    # PS-17, 完整视图核查
  pool_survival : 0.61                                     # PS-18, > 1/n = 0.25 可
  circuits:
    - { guard: 4a1f.., mid: 7c02.., exit: e9d3..,
        pivots:[{as:3356, jur:"US", c:0.5},{as:1299, jur:"SE", c:0.5}] }
    - { guard: b17c.., mid: 02aa.., exit: 55f1..,
        pivots:[{as:3320, jur:"DE", c:0.5},{as:9002, jur:"GB", c:0.0}] }
    - { guard: cc90.., mid: 1d44.., exit: a7e8..,
        pivots:[{as:6830, jur:"NL", c:0.5},{as:2914, jur:"JP", c:0.5}] }
    - { guard: 3e5b.., mid: f108.., exit: 9b22..,
        pivots:[{as:174,  jur:"US", c:0.0},{as:8075, jur:"IE", c:0.5}] }
```
正确地读（PS-9）：*「这 4 条链路**在地图 `H` 之下**按 AS 互不相交，而该地图容许一个 7%
的错误率；鉴于每个中继的 AS 被佐证得多么独立，这份按 AS 互不相交为真、而非一次误标的
产物的几率至少有 **70%**。它不是一个保证，而且它对一个地图看不见的数据中心只字未言
（§6.6）。」* 若操纵检测器触发了，上面的每一个数字都会被替换为
`class: none, confidence: 0, steering_flag: true` 以及一条回退警告——对一个被操纵的
客户端没有高置信度的证书。

```
  产出「链路与证书」的流程

   sample (PS-10)      map H + e (ID-12)      corroboration c_j (PS-15)
        │                   │                        │
        └─────────┬─────────┴──────────┬─────────────┘
                  ▼                     ▼
        ┌───────────────────┐   ┌──────────────────────────┐
        │ detect_steering   │   │ 认定-AS 互不相交的选取   │
        │ 在完整抽样上      │   │ (PS-2 顺序: as→node→none)│
        │ (PS-17, 防御 2)   │   │ + 池存活 (PS-18, 防御 1) │
        └─────────┬─────────┘   └──────────────┬───────────┘
                  │                            │ n 条链路 + 枢轴
          触发?   │                            ▼
         ┌────────┴────────┐       ┌────────────────────────────┐
        是               否  ─────▶│ confidence = Π(1−e(1−c_j))  │ PS-16
         │                 └──────▶│ class = 所满足的最强者      │
         ▼                         └──────────────┬─────────────┘
  class=none, conf=0                              ▼
  steering_flag=true         ┌─────────────────────────────────────┐
  → 回退 + gossip            │ CERTIFICATE {map_hash, map_error,   │
    (PS-8/9, ID-10)          │  circuits, corroboration, class,    │
                             │  confidence, steering_flag}         │

                     (裁决者是复现——无签名, ID-11)
```

- **PS-19（证书是给用户与对端双方的）。** `confidence` 与 `class` 必须（MUST）驱动
  用户所读到的 PS-9 如实呈现面（*今天这群人有这么互不相交，带着这么多的确定性*），且
  该证书必须（MUST）可被 gossip，使一个持有同一 `H` 的对端能重新推导它（PS-14），并
  使一处分歧——两个客户端，同一 `H` 与抽样，却是不同的证书——能被抓住并作为异常
  gossip 出去（ID-10），即第 8 部分用于地图分歧的那同一道免疫信号。UI 不得（MUST NOT）
  把 `confidence` 当作仿佛它为关联设了界限那样来引用：它为**内容**互不相交声称设界；
  元数据劣化得更快（PS-11(a)），而一个对 `class = as` 的高置信度并不意味着低的关联
  泄漏。

### 6.6 本程序不解决什么

该证书所背书的是**针对一个有界信任数据集的自洽，而非真正的互不相交**（第 8 部分 §10），
而整个程序的如实之处，就在于它在每一份记录上都这么说。一个把中继同址于一个机架、却
宣告着公开 BGP/RIR 数据**如实地**归属于不同 AS 的地址空间的对手，会被**正确的**地图
标为互不相交——于是查询与 `H` 相符，操纵检测器不触发（那个结构不是操纵签名，它就是
真实的公开路由表），池不塌缩，而枢轴被良好佐证，**因为每一个诚实视角都与地图一致**。
因此该程序会发出一份**高置信度的、却仍然错误的 `as` 证书**：`confidence` 衡量的是该
集合*在地图之下*互不相交的几率，而这里地图是对的，覆盖层却仍看不见那个机架。这就是
第 8 部分 §10 的同址残余，也是证书**无法**消除的那一项限制——再多的佐证都堵不上它，
因为佐证只能确认与*公开数据*的一致，而公开数据本身正是对手所满足的东西。它的量级恰为
模拟器在 `infer_error = 0` 处认定 AS 与真实 AS 之间的那道缺口：证书读作 1.0，现实却仍
可能碰撞，而唯有抬高 `k`/`n` 余量——而非任何证书字段——才能界定这一损失。证书的馈赠
在于它从不**隐藏**这一点：它陈述自己的误差区间，在操纵之下把自己压至零（PS-17/18），
且可被任何持有地图者核查（PS-14）。它把「按 AS 互不相交：是」——一个谎言——转化为
「在地图 `H` 之下、带错误 `e`、置信度 `c`、按 AS 互不相交」——一个真陈述，其仅剩的一处
盲点在此被点明、而别处无所隐藏。

另有三项限度是一次敌意审查所揭出的，在此申报而非粉饰过去：

- **边缘操纵逃过检测器。** 一份把诚实池铺散到足够多的伪造 AS 之上（`g ≥ 8`）的操纵
  地图，会构建出真正互不相交的链路，因而不会绊响单例比例检测器（PS-17）——但那时它的
  内容攻破仅约 5%，是一个小型合法网络的水平，并由 `k`/`n` 余量与 PS-16 置信度来界定。
  检测器抓住的是*有效*的操纵区间（10–100% 攻破），而非每一份地图。
- **一个撒谎客户端的置信度并不自证。** `confidence` 的如实程度，不过等同于发起方客户端
  所测量并放进证书的那些 `c_j` 与 `steering_flag`；一个夸大自己佐证、或略去一个标志的
  客户端，发出的证书重算起来自洽，却仍然错误（PS-14）。这个破绽是社会性的，而非算术性
  的：一个在同一 `H` 之上的独立客户端会推导出一份不同的证书，而该分歧会被作为异常
  gossip 出去（PS-19）。证书消除的是*悄无声息的*谎言，而非一个*可被检出的*谎言。
- **置信度乘积界定的是枢轴对的碰撞，而非每一种碰撞。** PS-16 衡量的是一对被认定为互不
  相交的枢轴*对*真正碰撞的几率。一次把一个枢轴与一个*中间*跳相碰撞的误标，或是把司法
  辖区错当成 AS 的误标，都在该乘积之外，必须（MUST）由对整条链路施加的 PS-2 互不相交性
  检验来抓住，而不能从置信度数字上读出。
