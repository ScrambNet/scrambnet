# ScrambNet 规范 —— 第 5 部分：断网与混合 mesh 的链路多样性

> **非规范性翻译。** 规范版本以英文为准（[en](../../en/spec/05-blackout-mesh.md)）。

**状态：草稿（DRAFT），也是一项已声明的研究风险。** 这是本项目里最大的尚未
写成的设计，而本部分——在路线图所允许的范围内——返回一个*部分的*结果：一个
扎实的混合网络模型，加上一个真正承重的想法（独立网关分散，作为一个*可用性*
性质），包裹在它以全强度点名、且不声称已关闭的那些残余之外。它**不承诺任何
具体的 mesh 栈**，也**不对无线电层作出任何匿名性声明**；它是一个姿态与模型的
部分，恰如第 4 部分那样。被标记为 `(s)` 的是 strawman 值。

先读 §3（那份现实性评估）——它是脊梁，而且它说出了本部分拒绝声明的那件大得
多的事。那唯一一个承重的正面声明是窄小的：*跨独立网关的分散，把 I-3 扩展到那个
物理邻里出口，作为一个可用性性质，而 mesh 中没有任何东西被允许去移动那条 I-2
内容下界*（BL-16）——mesh 之独立于那条下界，恰如第 4 部分让传输保持的那样
（CT-16）。本部分就是第 4 部分的 CT-18a 所交棒给的那个 L4 级，且它与那个让步
保持一致（BL-17）：当没有邻居时，什么也不被投递。

## 1. 那个混合网络模型与那些角色

- **BL-1（mesh 是一个层，而非一个模式）。「[规范性]」** 一个合规节点必须（MUST）
  *始终*把本地无线电链路与互联网链路当作共存的链路类型来对待，而非一个在基础
  设施丢失时才进入的「断网模式」。失去上行链路必须（MUST）是一次*路由*的改变
  （向一个网关多走一跳），而绝非一次协议、身份或安全姿态的改变。一个让用户切换
  的、有别的「mesh 模式」的设计，对这个取景而言是不合规的（OP-6）。
- **BL-2（角色，按硬件现实而定）。「[规范性]」** 一个节点必须（MUST）从它实际
  的无线电能力出发，把自己恰好归类为以下之一：**leaf**（一部手机：STA+AP 或
  Wi-Fi Aware 并发，受电池所界，无 root）、**backbone**（一台跑着真正 802.11s、
  持续存储转发的双无线电 PC/SBC），或 **gateway**（一个当前持有上行链路并宣告它
  的 backbone 或 leaf）。角色是能力派生且随时间变化的——一个失去上行链路的网关
  变成 backbone 或 leaf——而绝非一个固定的层级。
- **BL-3（主动选择加入是任何无线电链路的一个前置条件）。「[规范性]」** 一个
  节点不得（MUST NOT）在没有一个事先的、明确的、知情的、*专门针对 mesh 参与*
  且有别于任何中继 opt-in 的主动选择加入之前，在一条本地无线电链路上发起、转发
  或网关任何流量，因为 mesh 的可见性是物理的（BL-18），并且携带一个覆盖层无法
  轮换的无线电层身份（BL-18a）。沉默，或承袭那个中继 opt-in，是不合规的。
- **BL-4（诚实的电池与存储预算）。「[规范性]」** 一个 leaf 节点必须（MUST）在
  opt-in 之前，浮现它将实际承担的电池与存储代价（strawman：一个有界的存储转发
  配额和一个按占空比调度的无线电日程），并且不得（MUST NOT）承诺它在电池下无法
  维持的那种持续的、骨干级的可用性。那个具体预算是 OP-6 开放的，且必须（MUST）
  被声明，而非被猜测（BL-20）。

## 2. 独立网关分散、寻址、载运与混合

### 2.1 独立网关分散（那个承重的想法，作为可用性）

- **BL-5（份额应当通过独立网关离开）。「[规范性]」** 当一条消息的 `n` 份份额
  （SP-2）穿过本地 mesh 去往一条上行链路时，一个合规客户端应当（SHOULD）这样
  路由它们，使它们通过*不同的*网关离开，把 I-3（无单点）扩展到那个物理邻里出口。
  一个网关承载那 `n` 份份额中的 `k` 份就是一个单点，且在 ≥2 个独立-*估计*网关
  （BL-6）可及之处必须（MUST）被避免。在一场深度断网里那个独立性估计可能是空的
  （BL-6）；BL-5 此时**按默认**降级到 BL-7，而非作为一个边缘情形。此处所声明的
  好处是**可用性**，而非不可观测性（§3）：没有任何单个网关的失败、封堵或女巫
  俘获能杀死投递——这是 CT-15 为传输所下的那个裁断，搬到 mesh 空间里。
- **BL-6（「独立」在无线电层能意味着什么——被陈述，而非被解决）。
  「[规范性，声明残余]」** 一个合规客户端不得（MUST NOT）根据*自我声明*把网关
  当作独立的（GR-3，在无线电空间里）。「独立」只能从*可观测、非自我声明*的信号
  来估计——相异的上行链路 AS *在一张 AS 映射（第 8 部分）可及之处*、相异的无线电
  下一跳、相异的物理方向——其中每一个都是弱的、可伪造的，或**在一场断网里不可用**
  （那张 AS 映射，那个最强的信号，往往是最先失去的东西）。因此「独立网关」诚实
  的含义是一个**有界信任估计**，而非一个已核验的事实（§4b）；一个客户端必须
  （MUST）将它如此呈现，并且不得（MUST NOT）声称已核验的网关独立性。参见 BL-21
  ——这是那个在无线电空间里反复出现的独立性问题。
- **BL-7（太少——或为零——的独立网关会降级，绝不开放式失败）。「[规范性]」**
  在少于两个独立-估计网关可及之处，一个客户端不得（MUST NOT）悄无声息地把 `k`
  份份额推过一个网关、仿佛分散成立；它必须（MUST）为一个稍后的独立出口扣住份额
  （受 BL-12 TTL 所界）、把它们在时间上摊开，或浮现出对这条消息而言那个物理出口
  是一个单点（BL-19）。那条下界（I-2）无论哪一种都不受影响（BL-16）。

### 2.2 不依赖全局可达性的寻址

- **BL-8（名字存活；全局路由不存活）。「[规范性]」** 那个中继/收件人的 Ed25519
  `id`（第 2 部分）以及第 6 部分的 `box_id`/会合点，必须（MUST）在一场断网里
  仍然是稳定的名字；坏掉的是全局*可达性*，而非命名。一个节点不得（MUST NOT）
  为 mesh 上的下一跳选择而依赖于一个可及的 DHT 或任何全局路由。
- **BL-9（没有 DHT 的下一跳——那份菜单及其代价）。** 在没有一个全局路由之处，
  一个 mesh 下一跳是用一个有界代价的本地方法来选择的：朝向任一上行链路的疫情式
  泛洪（便宜、无需目的地知识、无线电代价高）；一个让邻居们宣告*朝向一个网关*
  （绝非朝向那个具名收件人，那会是一个选择子，I-4/SP-7）的可达性*梯度*；或物理
  携带（存储转发，直到一个网关进入射程）。本条款点名那份菜单；那个选择是一个
  strawman（BL-20），而每个选项都必须（MUST）保全 SP-7（字节上没有跨路径可链接
  性）与 I-4（BL-15）。
- **BL-10（投递仍然经由第 6 部分的死信箱运行，绝不送往一个具名设备）。
  「[规范性]」** mesh 的工作在那个*上行链路*处终止：一旦份额到达互联网，它们就
  重新进入覆盖层，并被投递到分散的死信箱（第 6 部分），一如既往。mesh 不得
  （MUST NOT）尝试直接投递到一个具名收件人*设备*——那会使投递以一个人为目标，
  违背第 6 部分的契约（RZ-1）。那个真正全本地的情形（发件人、死信箱与收件人全都
  在 mesh 内，无上行链路）由收件人的**死信箱**同样是 mesh-可及的来服务——存入与
  轮询都在 mesh 上*运行到一个死信箱*，而绝非运行到那个收件人设备——这就是第 6
  部分 §9 列为「断网期间在 mesh 上轮询（OP-6）」的那个开放项。路由到一个具名
  收件人设备依然作为一个选择子被禁止。

### 2.3 存储转发与那个取景裁断

- **BL-11（Sphinx 的有效性、而非字节，才是长程携带的约束）。
  「[规范性，声明残余]」** 那个 2048 字节的 Sphinx 包（SP-3）在*字节*上是自足的，
  但在*有效性*上不是：它的逐跳安全绑定到一个中继的 ≤7 天 `onion` 纪元（CH-5），
  以及那个逐纪元的重放缓存（SP-5、SP-7b）。一个在间歇性链路上被携带数小时至数天
  的包可能（MAY）比它第一跳所假设的那个纪元活得更久，或在重放状态已轮换、或在
  跨重启中已丢失之后才抵达。一个合规设计必须（MUST）陈述这一点，并且不得（MUST
  NOT）假设一个 Sphinx 包可以原封不动地被无限期携带。
- **BL-12（那个裁断：断网需要它自己的存储转发信封）。「[规范性]」** 由于 BL-11，
  以及由于存储转发需要那个固定 2048 字节的包没有余地容纳的字段（一个有界的生存
  时间、为间歇性链路而设的分片与重组、逐跳的保管信令），本草稿的裁断是
  **断网载运需要它自己的外层取景**——一个 DTN 风格的捆（现有技术：RFC 4838/5050），
  它*包裹*那个未经改动的内层 Sphinx 包，其自身被填充到固定长度，而它的元数据是受
  AEAD 保护的、绝非明文。那个内层包不被触动；那个信封是新的，且只存活在断网链路上。
  这是一个 strawman 裁断（BL-20），只能被一个关闭 BL-11 的论证推翻，而本草稿没有
  这样一个论证。
- **BL-13（那个信封不得变成一个选择子——并承袭 CT-6a 的嵌套残余）。
  「[规范性，声明残余]」** 那个信封的 TTL、分片索引与保管字段，恰恰就是 I-4 所
  禁止的那种明文元数据；它们必须（MUST）住在一个受 AEAD 保护、固定尺寸、外观
  统一的帧里（SP-4 纪律），并且不得（MUST NOT）让一个无线电观察者把一条消息的
  两个分片、或一条消息的两份份额，链接得比 SP-7 在覆盖层上已经允许的更好。**诚实
  的残余，承袭自第 4 部分：** 把一个 I-4-uniform 的内层包包裹进一个外层捆里，会在
  无线电空间里重新制造那个 **CT-6a 嵌套结构面**——一个固定尺寸的外层帧，其尺寸/
  时序/分片能泄露它承载着一个*第二*固定单元，而逐层的统一性**并不**使那个嵌套对
  一个 RF 观察者而言不可检测。这是一个已声明的残余，不被那个取景关闭。它仅在此处
  一切所是的那个意义上可存活：断网 RF 敌手是*本地的*，所以嵌套检测付出的代价是
  *参与的可观测性*——这正是 BL-18 已承认丢失的东西——并且**不**触及那条 I-2 内容
  下界。

### 2.4 无线电层混合 对 女巫网关

- **BL-14（女巫网关是一次物理日蚀；那个答案是部分的）。「[规范性，声明残余]」**
  一个宣告「我有上行链路」的节点会吸引邻里的流量，而一个女巫网关（或联盟）是
  一次*物理日蚀*——它是第 2 部分那个日蚀残余（OP-2）在无线电层的实例。那个部分
  的答案是 (i) 无线电层源混合（BL-15），使一个网关不能在*帧层*上轻易地把一份份额
  归因到它的发起邻居，与 (ii) 独立网关分散（BL-5）复合，使没有任何单个网关看到
  `k`。一个合规描述必须（MUST）声明这个答案是**部分的**：它抬高那个女巫的代价，
  它不移除那次日蚀，而它归约为 OP-1/OP-2 在无线电层上反复出现（BL-6、BL-21）。
- **BL-15（无线电层源混合是一项可用性/反日蚀措施，而非来源隐藏）。「[规范性]」**
  一条本地无线电链路上的流量必须（MUST）在字节上对一个无线电观察者满足 I-4
  （固定尺寸的统一帧，BL-13），并且应当（SHOULD）施加源混合，使一份份额的即时
  帧级发送者不被那个帧标记为它的发起者。这**不是**那个 GR-8 目录采样防御（GR-8
  是针对映射日蚀，跨源类别去混合一个客户端的*所存样本*——一个针对不同敌手的不同
  机制），且不得（MUST NOT）借用它的名字或它的保证。而它也不得（MUST NOT）被
  呈现为隐藏那个*物理*发起者：一个带测向能力的本地敌手，不论帧内容如何都知道一次
  发射的物理发射体（BL-18），所以无线电源混合买到的是*针对一个女巫网关的反日蚀
  代价*，而绝非来源匿名性——这正是 CT-15a 为传输所施行的那同一个可链接性-对-
  可用性纪律。

## 3. 那份诚实的现实性评估（那条脊梁）

*（以第 4、8 与 11 部分的那种 §残余声音写就。本节就是本部分本身，而非一个
附录。）*

**什么是真正可被设计、且真实的。** 三样东西。第一，那个*混合网络模型*（BL-1）：
把无线电与互联网当作共存的链路类型，使得失去一条上行链路是多走一跳、而非一个
不同的世界——这是干净的、可搭建的，且有现有技术支持（Briar、Reticulum、
Yggdrasil/cjdns、Freifunk 已演示了其中的部件）。第二——那个让这个范式物有所值
的想法——*独立网关分散*（BL-5）：每一个网关 mesh 的那个经典的致命弱点是网关看到
一切，而 ScrambNet 用那个定义了整个网络的机制来回应它，把那 `n` 份份额摊开到多个
网关上，使没有任何单个物理出口看到 `k`。第三，那个*不变量护卫*（BL-16）：让那条
I-2 下界完全独立于 mesh 是否成形，不只是可被设计的，它是被强制的，而它正是第 4
部分施于传输的那同一个纪律。这三样是扎实的。

**但那个好想法是一个*可用性*想法，且绝不可被当作多于此的东西来卖。** 独立网关
分散在那个炽热断网威胁模型里，对*谁*或*哪里*助益甚微，因为两个残余与一个身份
泄漏把它作为一个匿名性机制而削弱了：你在一场断网里无法核验网关独立性（BL-6），
那个发射体可被物理定位（BL-18），而无线电层携带一个覆盖层无法轮换的身份
（BL-18a）。分散*所*投递的、且真正投递的，是可用性：没有任何单个网关的失败、
封堵或女巫俘获能杀死投递，而这甚至在每一个匿名性性质都已崩塌时依然成立。这正是
CT-15 为多掩护传输所下的那个裁断——可用性有，伪装无——而本部分把它钉死在那里
（BL-16）。被当作匿名性来卖它就会是一个过度声称；被当作可用性来卖它就是一个真实
的、非空洞的性质。

**什么是仅仅部分的。** 那个女巫网关 / 物理日蚀问题（BL-14）。无线电层源混合加上
独立网关分散，抬高了一次女巫日蚀的代价；它不移除它。一个控制了一个小邻里 mesh
里 `k` 个可及出口的网关联盟，对一个发件人的日蚀，恰如一个中继联盟在覆盖层上所做
的那样——OP-1 与 OP-2 在无线电空间里反复出现，而非一个新防御。「部分的」是那个
正确的词。

**什么是未被解决的——以全强度声明，三个残余。**

*第一，网关独立性核验（BL-6、BL-21）。* 你无法从一个网关自我声明的任何东西去
核验两个网关是独立的，而在一场断网内部它比在覆盖层上更糟：那张本可以让一个客户端
从非自我声明的数据*推断*独立性的 AS 映射（第 8 部分），其自身往往不可及——那个
唯一的工具恰恰在它最被需要之时失去，所以那个估计在一场深度断网里可能近乎为空
（BL-5 按默认降级到 BL-7）。这不是一个第 5 部分的孤儿：那个威胁模型把它点名为
本项目最深的那个反复出现的问题的一个面——核验一方的独立性而不信任它的自我声明
——它与中继（OP-1）、发布签名者（OP-8）与依赖作者（OP-2/RB）共享。那个诚实的答案
与那里相同：一个*有界的、已声明的残余*，去喂养一个带着附带误差的信任*估计*
（ID-12 风格），而非一个密码学检查。第 5 部分没资格成为这件事最终被解决之地。

*第二，而且不可约地，物理可定位性（BL-18）。* 一个炽热断网里的 mesh 节点是一个
处在一个物理地点的无线电发射机，而**没有任何覆盖层能把一个无线电发射体对一个
带测向器的敌手藏起来。** 这在范畴上比本规范里的任何别的东西都更难，因为 ScrambNet
里每一个别的威胁都是一个*远程*敌手在对字节作推理，而这是一个*本地*敌手带着一根
天线——恰恰因为他们强加了那场断网而在场。那整座密码学大厦运作于*字节揭示什么*
之上；可定位性根本不关乎字节，它是那个发射的电磁事实。本部分绝不可承诺 mesh 保全
匿名性，而它没有。

*第三——那个覆盖层最卖力去防的、而无线电撤销掉的泄漏（BL-18a）。* 可定位性是*你
在哪里*；身份是*你是谁*，而无线电层把两者都泄漏。一个 Wi-Fi/802.11s 无线电发出
ScrambNet 覆盖层从不触碰的持久性二层标识符——一个 MAC 地址（而 802.11s 配对可能
要求一个稳定的 MAC）、Wi-Fi Direct/Aware 服务与设备 ID、探测请求指纹，以及，面对
一个有能力的敌手，一个完全挺过 MAC 随机化的*硬件 RF fingerprint*（振荡器瑕疵）。
所以那整个覆盖层故事——轮换的 `id`、逐纪元的 `box_id`、逐关系的卡片（RZ-2）、
SP-7 的份额不可链接性——都坐在一个本地嗅探者直接读到的二层化名*之上*，而覆盖层的
轮换无法轮换它。而那个 mesh *拓扑本身*是一张可观测的 RF 映射：谁转发给谁，即便在
统一帧之下也在空中可见。这是本部分第一稿省略的那个唯一的残余；它在此处以全强度
被点名，因为它可以说比可定位性更糟——你不只在发射时是可被找到的，你每次加入都
携带一个稳定的无线电化名。

**mesh 能否保全它所承袭的那些不变量？部分地能，而这里是那份诚实的账本。**
**I-2（内容下界）：** 被干净地保全——那条下界从不骑在 mesh 上，一如它从不骑在传输
上（BL-16）；这是本部分所作的最强、最真的陈述。**I-4（线上统一性）与 SP-7（份额
不可链接性）：** **仅在字节层上**被保全——一个统一帧依然是一次可被检测的发射
（BL-18），而一条消息的两份份额从*同一个物理设备在同一个时间窗内*发出，会被测向
与时序所关联（无线电重新链接了覆盖层所解链的东西）；本部分不得（MUST NOT）声称
所承袭的字节不可链接性存活到了 RF 层。**I-3（无单点）：** 被*扩展*，作为一个
尽力而为的可用性性质，通过独立网关分散（BL-5）——但只到 BL-6 的估计可信的那个
程度，而这正是那个未被解决的残余。所以：I-2 被保全，I-4/SP-7 仅-在-字节上-被
保全，I-3 被扩展-但-为估计。那就是那份账本，而它是刻意反凯歌的。

**与 CT-18a 的一致性。** 第 4 部分承认，在一次没有 mesh 邻居的全面断网处，投递
为零，而那条下界是完好-且-无用的。第 5 部分是那个让步*之下*的那一级——当*确有*
一个邻居时你做什么——而它没有把它走回去。它把可达性往下扩展一层；它不使投递有
保证（BL-17）。那个诚实的声明不是「通信在 mesh 上总能穿过去」——而是：*当一个
mesh 邻居与一个网关存在时，一条消息能以一辆公交车的速度穿过城市；当一个都不存在
时，那个秘密留在家里，未被投递、也未被暴露；而无论哪一种情形，在 mesh 上发射都是
一个可被物理定位、可被无线电识别、而覆盖层无法隐藏的行为。*

这是一个 XL / 研究风险项，而它返回——在路线图所允许的范围内——一个*部分的*结果：
一个扎实的混合网络模型和一个真实的可用性想法，围绕着以全强度被点名、且不被声称
已关闭的那些残余（网关独立性、物理可定位性、无线电身份）。

## 4. 那两个经过论证的裁断

**(a) 那个 2048 字节的 Sphinx 包能否挺过数小时之久的存储转发，抑或断网需要它
自己的取景？→ 它需要它自己的取景（BL-11、BL-12）。** 那个包在*字节*上没问题，
但在*有效性与功能*上在三个独立的计数上失败：(1) 它的逐跳安全绑定到一个 ≤7 天的
`onion` 纪元（CH-5），而一次数天之久的携带能比它活得更久，抵达一把已轮换、已清零
的密钥处；(2) SP-5/SP-7b 要求逐纪元的重放状态挺过重启，而间歇性的无线电节点恰恰
在这数小时之久的时域上丢失电力与缓存；(3) 那个固定的 2048 字节布局（SP-3）没有
备用字段去容纳间歇性链路所需的 TTL、分片与保管信令，且不可以在明文里长出一个
（I-4）。那个干净的解法是一个 DTN 风格的外层捆，包裹那个未经改动的内层包
（BL-12/BL-13），带着那个已声明的 CT-6a 嵌套残余。这是一个 strawman 裁断，只能靠
关闭 BL-11 来推翻。

**(b) 网关独立性能否在无线电层被核验？→ 不能；它是一个喂养一个有界信任估计的
已声明残余（BL-6、BL-21）。** 「独立」本应在不信任那个网关所说之物的前提下被
确立（GR-3，在无线电空间里），而每一个可用的信号都是弱的或已失去的：相异的上行
链路 AS 需要第 8 部分的那张映射，*在那个独立性最要紧的断网内部恰恰不可及*；相异的
物理方向是可伪造且粗糙的；相异的无线电下一跳证明的是拓扑，而非出口独立性。不存在
一个能证明两个网关有独立上行链路的密码学检查——这与 OP-1 为中继不相交性所撞的、
以及 OP-8 为签名者司法辖区所撞的，是同一堵墙。所以那个诚实的架构与那个 AS 映射的
架构（ID-12）完全相同：别声称核验，从非自我声明的可观测量产出一个有界信任估计
（它在一场深度断网里可能近乎为空），附上那个不确定性，浮现它（BL-19），并让分散
（BL-5）与随时间的摊开（BL-7）去界住——而非移除——当那个估计出错时的那个危害。

## 5. 那些不变量与诚实护卫

- **BL-16（那条下界独立于 mesh 是否成功——那个 CT-16 类比）。「[规范性]」** 没有
  任何机密性或分散的保证（I-2）被允许（MUST）依赖于 mesh 成形、依赖于一个网关
  可及、依赖于那些网关真正独立（BL-6），或依赖于那个断网信封被投递。mesh 买到的
  是**可达性而已**——这与第 4 部分为传输所用的那个词相同。一个失去 mesh 就失去
  那条下界的设计是不合规的。
- **BL-17（与 CT-18a 的一致性：那个底部依然是一个底部，三个状态）。「[规范性]」**
  第 5 部分把可达性扩展到 CT-18a 之下一级，且不得（MUST NOT）被措辞成与它矛盾。
  那三个状态，全都明说：(1) **射程内无邻居** → CT-18a，零投递，下界完好-且-无用；
  (2) **射程内有邻居但 mesh 里任何地方都无网关可及** → *也*是零投递，经由 mesh
  而非直接抵达——存储转发可以（MAY）为一个 BL-12 TTL 内的*未来*网关而扣住份额，
  但这不得（MUST NOT）被呈现为投递；(3) **≥1 个网关可及** → BL-5/BL-7 分散或降级。
  状态 (2) 坍缩到与 (1) 相同的结局；只是路径不同。第 5 部分使投递在低一层*成为可能*，
  绝非*很可能*、也绝非*有保证*。
- **BL-18（物理可定位性残余——以全强度陈述，从不被解决）。「[规范性，声明残余]」**
  一个在炽热断网里发射的 mesh 节点是一个**可被物理定位的行为**：一个处在一个地点的
  无线电发射体，恰在那个强加了断网的本地敌手最具侵略性、最愿意动用测向与
  IMSI-catcher 式手法的那一刻。**本规范里没有任何覆盖层、混合、分散或取景隐藏这
  一点，而本部分不得（MUST NOT）声称或暗示它做到了。** 这就是为什么 mesh 参与必须
  （MUST）是一个明确的、知情的、逐语境的 opt-in（BL-3），也是为什么本部分那个诚实
  声明是窄小的（§3）。
- **BL-18a（无线电层身份残余——被声明，而非被解决）。「[规范性，声明残余]」**
  mesh 参与暴露那些覆盖层无法轮换的持久性二层标识符：一个 MAC 地址（802.11s 配对
  可能要求一个稳定的 MAC）、Wi-Fi Direct/Aware 设备与服务 ID、探测请求指纹，以及
  ——面对一个有能力的敌手——一个挺过 MAC 随机化的*硬件 RF fingerprint*。每一个都是
  那个*设备*的一个稳定化名，独立于每一次覆盖层轮换（`id`、`box_id`、RZ-2 卡片、
  SP-7）。MAC 随机化对第一类有帮助，对 RF fingerprinting 则毫无帮助。那个 mesh
  *拓扑*同样是一张可观测的 RF 映射——谁转发给谁，即便在统一帧之下也在空中可见。
  本部分不得（MUST NOT）暗示覆盖层的不可链接性延伸到那个无线电发射体。这是那个在
  无线电空间里反复出现的身份/独立性问题的第二个面，与网关独立性（BL-21）并列，被
  声明而不被关闭。
- **BL-19（诚实地浮现那个 mesh 姿态——那个 CT-19 类比）。「[规范性]」** 一个合规
  客户端必须（MUST）在那个既有的诚实面（PS-9/CT-19）上浮现：一条无线电链路正在
  使用中；这条链路是*可被物理定位*的（BL-18）**且可被无线电识别**的（BL-18a）；
  它的网关出口是单个的、还是复数-且-独立-*估计*的（BL-6/BL-7）；以及 mesh 可达性
  ——与那条 I-2 下界不同——携带**不出**任何保证且可能为零。那个 UI 所陈述的消息：
  *你的内容下界成立；在 mesh 上，你能被定位，而你的设备能在你所站之处在空中被认出。*
- **BL-20（具体的栈被留为开放；声明以实际所运行之物为界）。「[规范性]」** 第 5
  部分**不**强制一个具体的无线电栈、路由方法（BL-9）、TTL/分片尺寸（BL-12），或
  电池预算（BL-4）；这些是 strawmen 和所有者决定。一个 mesh 栈未指定的客户端不得
  （MUST NOT）声称任何*定量的* mesh-可用性性质；它只可以（MAY）声称那个*定性的*
  「一个失去上行链路的节点能向一个邻居网关多走一跳，而份额应当（SHOULD）通过
  独立-估计网关离开」，并且只在它实际运行 ≥2 个独立-估计网关、且 `k < n` 之处。
- **BL-21（那个反复出现的独立性问题被声明，而非被关闭）。「[规范性，声明残余]」**
  在没有一张可及映射、且位置为自我声明之下（BL-6）去核验网关独立性，是**那个为
  中继（OP-1）、发布签名者（OP-8）与依赖作者（OP-2/RB）出现的同一个问题**——核验
  一方的独立性而不信任它的自我声明——现在在一场断网内部戴着它的无线电层面具，而
  那里那张 AS 映射（第 8 部分）其自身不可及。第 5 部分**不**解决它；它把它归约到
  那个已声明的反复出现的残余，并喂养一个有界信任估计，恰如那张映射用一个已声明的
  错误率喂养一个（ID-12）。

## 6. 此处引入的需求

- **BL-1 / BL-2 / BL-3 / BL-4** —— mesh 是一个层而非一个模式；能力派生、随时间
  变化的角色；在任何无线电链路之前的明确逐语境 opt-in；一份诚实的电池/存储预算。
- **BL-5 / BL-6 / BL-7** —— 独立网关分散作为可用性；「独立」是一个有界信任估计，
  绝非自我声明、且在一场深度断网里近乎为空；太少/为零的网关会降级，绝不开放式失败。
- **BL-8 / BL-9 / BL-10** —— 名字存活，路由不存活；没有 DHT 的下一跳及其代价；
  投递仍然经由第 6 部分的死信箱运行、绝不送往一个具名设备，而那个全本地情形由一个
  mesh-可及的死信箱来服务。
- **BL-11 / BL-12 / BL-13** —— Sphinx 的有效性（而非字节）界住长程携带；断网需要
  它自己的 DTN 风格信封；那个信封不得是一个选择子，且承袭 CT-6a 的嵌套残余。
- **BL-14 / BL-15** —— 女巫网关是一次物理日蚀，仅被部分地回答；无线电源混合是
  一项可用性/反日蚀措施，**不是** GR-8 且**不是**来源隐藏。
- **BL-16 / BL-17** —— 那条下界独立于 mesh；与 CT-18a 的一致性，那三个投递状态，
  那个底部依然是一个底部。
- **BL-18 / BL-18a / BL-19** —— 物理可定位性与无线电身份，二者皆以全强度被声明且
  从不被解决；PS-9 上的诚实 mesh 姿态。
- **BL-20 / BL-21** —— 具体的栈被留为开放；那个反复出现的独立性问题被声明，而非
  被关闭。

BL-16 与 BL-18/BL-18a 是承重的三条：那条下界不依赖于 mesh，而 mesh 无法隐藏你
正在发射、或你的设备在空中可被认出。那个诚实的声明是窄小且可用性形状的：*mesh
把可达性扩展到一次关停之下一级，并守住它所承袭的内容下界，但它不隐藏那个发射体、
那个设备或那个拓扑，而它不保证投递。* 打破本部分，靠点名一种这些条款在
BL-18/BL-18a 之外许诺的 mesh 层匿名性、一处那条 I-2 下界在 BL-16 之外被弄成依赖于
mesh 成功的地方、一条把 BL-17 读作把「可能」升级为「很可能」的途径，或一个
BL-18/BL-18a 漏掉的无线电层泄漏。那就是那个邀请，以那种家宅之声——而在本部分上
尤其，对「它解决了断网吗？」那个诚实的答案是「部分地，而这里恰恰是它没有之处」。
