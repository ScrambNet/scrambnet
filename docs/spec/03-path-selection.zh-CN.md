# ScrambNet 规范 —— 第 3 部分：链路构建与路径选择

**状态：草稿（DRAFT），也是本规范中最不稳定的部分。** 这是*运维*安全的承重墙
（I-2 所保障的内容下界没有它也能成立，但抗关联保护与整套 k-路径的故事都栖身于此）。
临时取值以 `(s)` 标记。disjoint（互不相交）性的验证问题即 OP-1，且公开地悬而未决；
本部分陈述目标，并给出一个可供攻击的首个机制。

## 1. 范围，以及为什么这很难

分散（第 1 部分）使内容在被捕获的 `k` 份额以下无条件安全。只有当 `n` 条份额链路
真正互不相交时，那条保证才在*运维*意义上成立——否则对手的单个观测点便能看见 `k`
份额，而那条下界虽在数学上完好无损，却永远无法企及。本部分决定一个客户端——它仅持有
自己那份可验证的 gossip 抽样（第 2 部分），并无任何可信地图——如何选出 `n` 条让对手
无法廉价地横跨其上的链路。此处的一切都必须能抵挡这样的中继：它们对一切都撒谎，唯独
对其签名所绑定之物不能（GR-2）。

## 2. 互不相交性目标

- **PS-1.** 一条消息的 `n` 条链路必须（MUST）*按节点互不相交*：没有任何中继出现在
  其中两条之上。这是下界，只要抽样足够大便始终可强制施行。
- **PS-2.** 客户端应当（SHOULD）另行追求如下目标，按价值递减、难度递增的顺序：
  **按 AS 互不相交**（没有任何两条链路在守卫或出口处共享同一自治系统），其次
  **按司法辖区互不相交**（没有任何两条共享同一法律辖区）。它无法满足的每一层级都
  必须（MUST）向用户报告，而非悄然跳过（PS-9）。
- **PS-3.** 在同一条链路内，守卫、中间节点与出口必须（MUST）按节点各不相同，并应当
  （SHOULD）按 AS 各不相同。一条守卫与出口共享同一 AS 的链路，是送给端到端关联的
  大礼，只要存在任何替代方案便禁止（MUST NOT）使用。

## 3. 无需自我申报的推断

- **PS-4.** GR-3 禁止中继申报其位置，因此客户端从每个中继的 `addrs` 出发，使用
  *自己的*数据集（例如一份定期刷新的 IP-到-AS 映射）来推断该中继的 AS 与司法辖区，
  绝不采信中继自身所言。该数据集的分发本身必须（MUST）遵守 I-3：不存在任何单一的
  权威来源（候选设计即 OP-1）。
- **PS-5.** 推断是不确定的，客户端必须（MUST）如此对待它：当某中继的 AS 或司法辖区
  未知时，它便计为与其他每一个未知项*可能共享*——取保守假设，绝不取乐观假设。

## 4. 守卫

- **PS-6.** 每个客户端维护一小组**守卫中继**（临时方案：每个链路位置一个主守卫，
  按月而非按分钟的节奏轮换），沿用 Tor 的守卫论证：快速轮换入口点会成倍放大最终抽中
  一个敌意入口的概率。各守卫之间必须（MUST）选为按 AS 互不相交，使得 `n` 条链路不会
  在入口处汇集穿过同一个 AS。
- **PS-7.** 守卫的选取按*已验证*带宽（GR-7）加权，绝不按声称的带宽；一个带有无法
  验证之声称的中继，被当作低带宽处理，而非高带宽。

## 5. 小型网络：降级，并把它说出来

- **PS-8.** 当客户端已验证的抽样无法提供 `n` 条按 AS 互不相交的链路时，它必须
  （MUST）按固定顺序回退——按 AS 互不相交 → 按节点互不相交 → 独立抽取——并且不得
  （MUST NOT）悄然像更强的性质仍然成立那样继续下去。当估计出的可行规模未达标时，
  参数可以（MAY）下调（小型网络模式：`n = 2, k = 2`，并尽力而为地做到互不相交）。
- **PS-9.** 客户端必须（MUST）将一条消息实际达到的互不相交层级，以非专家也能正确
  读懂的措辞公开出来：今天的人群很小；这就是你买到的东西。内容下界（I-2）与关联层级
  是彼此独立的陈述，必须（MUST）分别展示。

- **PS-10（抗女巫的规模估计）。** 可行规模的估计必须（MUST）只计入独立验证过的中继
  与观测到的 AS 多样性，绝不计入原始的记录条数，以免对手用女巫节点把网络吹胀，从而
  诱使客户端采用其多样性为假的完整参数（与 OP-2 相关联）。

## 6. 本部分不作决定之事

互不相交数据集的无信任分发，以及对所选集合是否如所声称般互不相交的形式化验证
（OP-1）；诚实的可行规模阈值，以及 `n = 2, k = 2` 究竟是否值得运行（OP-3）；守卫
轮换的经济学；在断网网状网上的路径选择——那里 AS 与司法辖区均无意义（OP-6）。
`poc/network_sim.py` 是本部分背后那个可运行的临时方案——先攻击它的模型，再攻击
这段文字。
